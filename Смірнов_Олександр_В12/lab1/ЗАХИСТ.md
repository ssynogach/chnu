## 3. Формат файлів

```
ТЕКСТОВИЙ (task1_input.txt)            БІНАРНИЙ (task1_input.bin)
┌────────────────────────┐             ┌──────────────────────────────┐
│ 5                      │ ← n         │ 05 00 00 00  ← n (4 байти)   │
│ 1 2 3 4 5              │ ← елементи  │ 8 байт × n   ← елементи      │
└────────────────────────┘             └──────────────────────────────┘
```

**Завдання 3.** Число `n` у файлі — це кількість **чисел**, тобто `1 + n × m`. Перше з них — `m` (ширина рядка):

```
m   A(1) A(2) ... A(m)   A(m+1) ... A(2m)   ...
└┘  └──── 1-й рядок ───┘ └──── 2-й рядок ──┘
```

Приклад для матриці 2×3 (`1 5 2 / 9 3 4`): у файлі `7` (кількість), далі `3 1 5 2 9 3 4`.

## 4. Розв'язок завдань

### 🔹 Завдання 1 — середнє арифметичне

```
sum = a[0] + a[1] + ... + a[n-1]      (вказівник p іде від a до end)
avg = sum / n
```

Приклад: `4 -2 7 10 3 -8` → сума = 14, n = 6 → **2.33333**

> `sum` має тип `double`, тому ділення дробове (не відкидає частину).

### 🔹 Завдання 2 — номер останнього мінімального серед елементів < T1 правіше першого T2

Алгоритм через вказівники:

```
1. p іде від початку, поки *p != T2        → зупинилися на першому елементі, рівному T2
2. якщо p дійшов до кінця                  → T2 немає → відповіді немає
3. p++                                     → починаємо правіше T2
4. для кожного елемента:
      якщо *p < T1                         → кандидат
         якщо best порожній АБО *p <= *best → best = p
5. номер = best - a                        → різниця вказівників
```

Приклад: масив `5 3 -1 7 2 -4 0 6`, **T1 = 5, T2 = 3**

```
індекс:  0  1   2  3  4   5  6  7
значення 5  3  -1  7  2  -4  0  6
            ↑  └────────────────┘
          перший 3     правіше: -1, 7, 2, -4, 0, 6
                       з них < 5: -1, 2, -4, 0  → мінімум -4 → індекс 5
```

> `<=` (а не `<`) — ключова деталь: при однакових значеннях `best` пересувається правіше, тому лишається **останній** мінімальний.
> Сам елемент, рівний T2, **не** розглядається (він не «правіше» себе) — тому `p++` перед циклом.

### 🔹 Завдання 3 — мінімум із максимумів рядків

```
для кожного рядка i:  mx = max(a[1+i*m] ... a[1+i*m+m-1])
V = min(mx_0, mx_1, ..., mx_{n-1})
```

Приклад `2 × 3`:

```
1 5 2   → max = 5
9 3 4   → max = 9
V = min(5, 9) = 5
```

Масив зберігається в одному ряду, тому i-й рядок починається з `a + 1 + i*m` (`+1` — бо в `a[0]` лежить m).
Обмеження `n ≤ 100`, `m ≤ 15` контролюють цикли `do { … } while (…)`.

## 5. Питання викладача та відповіді

### 🧠 Пам'ять і масиви

**Навіщо динамічний масив і `new`?**
Розмір `n` вводить користувач уже під час роботи програми, а звичайний масив `int a[100]` має фіксований розмір. `new double[n]` виділяє рівно стільки пам'яті, скільки потрібно.

**Що буде, якщо не написати `delete[]`?**
Витік пам'яті: вона лишається зайнятою до завершення програми.

**Різниця між `delete` і `delete[]`?**
`delete` — для однієї змінної (`new int`), `delete[]` — для масиву (`new int[n]`).

**Що таке `vector` і навіщо він тут?**
Динамічний масив зі стандартної бібліотеки: сам керує пам'яттю, знає свій розмір (`v.size()`), додає елементи через `push_back`. У лабі ним виводимо вміст файлу — так вимагає завдання.

**Чим `vector` зручніший за `new[]`?**
Не треба вручну писати `delete[]`, неможливо забути й отримати витік, є `size()`.

### 📌 Вказівники

**Що таке вказівник?**
Змінна, що зберігає *адресу* іншої змінної. `*p` — значення за цією адресою, `p++` — перехід до наступного елемента масиву.

**Як `best - a` дає номер елемента?**
Обидва вказівники вказують у один масив. Їхня різниця — це кількість елементів між ними, тобто індекс.

**Чому `*p % 2 == 0`, а не `p % 2 == 0`?**
`p` — це адреса. Парність перевіряємо в **значення**, тому потрібна зірочка.

**Що таке `end = a + n`?**
Вказівник на місце одразу **після** останнього елемента. Умова `p < end` означає «ще не вийшли за масив».

### 📁 Файли

**Чим текстовий файл відрізняється від бінарного?**

| | Текстовий | Бінарний |
|---|---|---|
| Вміст | числа як символи (`"12 5"`) | байти, як у пам'яті |
| Читається в блокноті | так | ні |
| Розмір | більший | менший |
| Відкриття | `ofstream f(name)` | `ofstream f(name, ios::binary)` |
| Запис / читання | `<<` / `>>` | `write` / `read` |

**Що робить `f.write((char*)a, n * sizeof(double))`?**
Записує `n * 8` байтів, починаючи з адреси `a`. `(char*)` — перетворення вказівника на «байтовий», бо `write` приймає саме `char*`. `sizeof(double)` — розмір одного числа в байтах.

**Навіщо спочатку записувати `n` у файл?**
Щоб при читанні знати, скільки місця виділити під масив і скільки чисел читати.

**Що означає `if (!f)` для файлу?**
Файлова змінна перетворюється на `false`, якщо файл не відкрився. Тобто «якщо файлу немає».

**Навіщо `readD` повертає `NULL`?**
Це сигнал для викликаючого коду: «читати нічого, пропусти розв'язок».

**Що таке `ios::binary`?**
Режим відкриття без перетворення символів (наприклад, переносу рядка на Windows). Обов'язковий для бінарних даних.

### ⚙️ Синтаксис

**Навіщо `int& n` у `readD(const char* name, int& n, ...)`?**
`&` — передача за посиланням: функція змінює саму змінну `n` у викликаючому коді. Так функція «повертає» дві речі: масив (через `return`) і його розмір (через `n`).

**Чому `const char*` для імені файлу?**
Рядок у лапках має саме такий тип. `const` означає, що функція рядок не змінює.

**Як працює `rand() % 201 - 100`?**
`rand() % 201` дає число від 0 до 200, мінус 100 → від −100 до 100. Загальна формула: `rand() % (кількість_значень) + найменше`.

**Навіщо `srand(time(0))`?**
Без нього `rand()` щоразу видає ту саму послідовність. `time(0)` — поточний час у секундах, він щоразу інший, тож числа різні.

**Навіщо `do { … } while (choice != 0)`?**
Меню показується мінімум раз і повторюється, доки користувач не введе 0.

**Навіщо `printMenu`?**
Текст меню в трьох завданнях однаковий — винесено в одну функцію, щоб не копіювати. Номер завдання передається параметром.

**Чому `using namespace std;`?**
Щоб писати `cout`, `vector` замість `std::cout`, `std::vector`.

### 📊 Загальне

**Складність алгоритмів?**
Усі три — **O(n)** (у завданні 3 — O(n·m): один прохід по всіх елементах матриці).

**Що буде, якщо ввести `n < 1` у завданні 1 чи 2?**
У завданні 1 є окрема перевірка `n == 0` (повідомлення «Масив порожній»), у завданні 3 цикл `do … while` не пропускає n, m поза межами.

## 6. Правки «на льоту»

| Що попросять | Що змінити |
|---|---|
| Максимум замість середнього (завд. 1) | у циклі `if (*p > mx) mx = *p;` замість додавання |
| Шукати **перший** мінімальний, а не останній | завдання 2: `*p <= *best` → `*p < *best` |
| Мінімальний → **максимальний** | завдання 2: `*p < t1` лишається, `*p <= *best` → `*p >= *best` |
| «Лежать **лівіше** першого T2» | зупинитись на T2 і дивитися елементи **до** `p`: `for (q = a; q < p; q++)` |
| `max` з мінімумів рядків (замість `min` з максимумів) | завдання 3: у внутрішньому циклі `p[j] < mn`, зовні `mx > v` |
| Інший діапазон генерації | число після `%` і число, яке віднімаєш, у рядку з `rand()` |
| Рахувати номер **з одиниці** | у завданні 2 вивести `index + 1` (вже виводиться обидва варіанти) |
| Менше/більше рядків у матриці | змінити межі `100` і `15` в умовах `do … while` |

## 7. Код з коментарями

> Це та сама програма, що й у `main.cpp`, лише з поясненнями. Після видалення коментарів код збігається з оригіналом рядок у рядок (перевірено). Модулі 0–7 позначені в коментарях.

```cpp
// МОДУЛЬ 0. Підключення бібліотек
#include <iostream>                           // cin, cout - ввід і вивід
#include <fstream>                            // ofstream, ifstream - файли
#include <vector>                             // vector - контейнер для показу файлу
#include <cstdlib>                            // rand, srand - випадкові числа
#include <ctime>                              // time - поточний час (для srand)

using namespace std;                          // щоб писати cout замість std::cout

// МОДУЛЬ 1. Файли для double (завдання 1 і 3)
// writeD - запис масиву у файл. binary = true -> бінарний, false -> текстовий
void writeD(const char* name, double* a, int n, bool binary) {
    if (binary) {
        ofstream f(name, ios::binary);        // відкриваємо для запису в бінарному режимі
        f.write((char*)&n, sizeof(n));        // спочатку кількість елементів (4 байти)
        f.write((char*)a, n * sizeof(double)); // потім усі елементи одним шматком (n*8 байт)
        f.close();
    } else {
        ofstream f(name);                     // звичайний текстовий файл
        f << n << endl;                       // перший рядок - кількість елементів
        for (int i = 0; i < n; i++) {
            f << a[i] << " ";                 // другий рядок - елементи через пробіл
        }
        f << endl;
        f.close();
    }
}

// readD - читання файлу в новий динамічний масив. n повертається через посилання (&).
// Якщо файлу немає - повертає NULL
double* readD(const char* name, int& n, bool binary) {
    ifstream f;
    if (binary) {
        f.open(name, ios::binary);
    } else {
        f.open(name);
    }
    if (!f) {                                 // файл не відкрився
        cout << "Файл " << name << " не знайдено!" << endl;
        n = 0;
        return NULL;
    }
    if (binary) {
        f.read((char*)&n, sizeof(n));         // читаємо кількість елементів
    } else {
        f >> n;
    }
    double* a = new double[n];                // виділяємо пам'ять під n елементів
    if (binary) {
        f.read((char*)a, n * sizeof(double)); // читаємо всі елементи одразу
    } else {
        for (int i = 0; i < n; i++) {
            f >> a[i];
        }
    }
    f.close();
    return a;                                 // віддаємо масив (delete[] робить той, хто викликав)
}

// showD - читає файл і виводить його через vector (вимога п. 3d умови)
void showD(const char* name, bool binary) {
    int n;
    double* a = readD(name, n, binary);
    if (a == NULL) {
        return;
    }
    vector<double> v;
    for (int i = 0; i < n; i++) {
        v.push_back(a[i]);                    // додаємо елемент у кінець вектора
    }
    delete[] a;                               // масив більше не потрібен - звільняємо пам'ять
    cout << "Вектор з файлу " << name << ":" << endl;
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }
    cout << endl;
}

// МОДУЛЬ 3. printMenu - меню підзавдання (однакове для всіх трьох завдань, змінюється лише номер)
void printMenu(int task) {

// що лежать правіше першого елемента, рівного T2

            cout << "Записано в task2_input.bin" << endl;
        }
        else if (choice == 3 || choice == 4) {
            int n;
            int* a;
            if (choice == 3) {
                a = readI("task2_input.txt", n, false);
            } else {
                a = readI("task2_input.bin", n, true);
            }
            if (a != NULL) {
                cout << "Масив:" << endl;
                for (int i = 0; i < n; i++) {
                    cout << a[i] << " ";
                }
                cout << endl;

                int t1, t2;                   // порогові значення T1 і T2 з умови
                cout << "Введіть T1: ";
                cin >> t1;
                cout << "Введіть T2: ";
                cin >> t2;

                int* p = a;                   // вказівник на поточний елемент (початок масиву)
                int* end = a + n;             // вказівник на місце ПІСЛЯ останнього елемента
                while (p < end && *p != t2) { // КРОК 1: шукаємо перший елемент, рівний T2
                    p++;                      // переходимо до наступного елемента
                }

                int* best = NULL;             // вказівник на найкращий елемент (поки такого немає)
                if (p < end) {                // T2 знайдено (p не вийшов за межі масиву)
                    p++;                      // переходимо до наступного елемента
                    while (p < end) {
                        if (*p < t1) {        // елемент менший за T1 - кандидат
                            if (best == NULL || *p <= *best) { // <= (а не <) - щоб лишився ОСТАННІЙ мінімальний
                                best = p;     // запам'ятуємо адресу кандидата
                            }
                        }
                        p++;                  // переходимо до наступного елемента
                    }
                }

                ofstream f("task2_result.txt");
                if (best == NULL) {
                    cout << "Такого елемента немає" << endl;
                    f << "Такого елемента немає" << endl;
                } else {
                    int index = best - a;     // різниця вказівників = індекс елемента
                    cout << "Номер елемента (з нуля): " << index << endl;
                    cout << "Номер елемента (з одиниці): " << index + 1 << endl;
                    cout << "Значення: " << *best << endl;
                    f << "Номер (з нуля): " << index << ", значення: " << *best << endl;
                }
                f.close();
                cout << "Результат записано в task2_result.txt" << endl;
                delete[] a;                   // масив більше не потрібен - звільняємо пам'ять
            }
        }
        else if (choice == 5) {
            showI("task2_input.txt", false);
        }
        else if (choice == 6) {
            showI("task2_input.bin", true);
        }
    } while (choice != 0);                    // повторюємо меню, доки не введено 0
}

            } else {

                writeD("task3_input.bin", a, total, true);
                cout << "Згенеровано (перше число - m, далі n*m елементів):" << endl;
                for (int i = 0; i < total; i++) {
                    cout << a[i] << " ";
                }
                cout << endl;
                cout << "Записано в task3_input.bin" << endl;
            }
            delete[] a;                       // масив більше не потрібен - звільняємо пам'ять
        }

            int total;
            double* a;

                a = readD("task3_input.txt", total, false);
            } else {
                a = readD("task3_input.bin", total, true);
            }
            if (a != NULL) {
                int m = (int)a[0];            // перший елемент файлу - це m (кількість стовпців)
                if (total < 2 || m < 1 || (total - 1) % m != 0) { // перевірка, що файл має правильну форму (1 + n*m чисел)
                    cout << "Неправильні дані у файлі!" << endl;
                } else {
                    int n = (total - 1) / m;  // кількість рядків n = (усі числа - 1) / m
                    cout << "Масив " << n << " x " << m << ":" << endl;
                    for (int i = 0; i < n; i++) {
                        for (int j = 0; j < m; j++) {
                            cout << a[1 + i * m + j] << " ";
                        }
                        cout << endl;
                    }

                    for (int i = 0; i < n; i++) {
                        double* p = a + 1 + i * m; // вказівник на початок i-го рядка (a[0] - це m, тому +1)
                        double mx = *p;       // максимум рядка - спочатку перший елемент
                        for (int j = 1; j < m; j++) {
                            if (p[j] > mx) {  // знайшли більший - оновлюємо максимум
                                mx = p[j];
                            }
                        }
                        cout << "max рядка " << i + 1 << " = " << mx << endl;
                        if (i == 0 || mx < v) { // V = мінімум з максимумів рядків (перший рядок задає початкове V)
                            v = mx;
                        }
                    }

                    cout << "Результат записано в task3_result.txt" << endl;

}
```
