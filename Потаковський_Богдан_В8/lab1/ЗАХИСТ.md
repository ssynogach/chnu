## 3. Формат файлів

```
ТЕКСТОВИЙ (task2_input.txt)            БІНАРНИЙ (task2_input.bin)
┌────────────────────────┐             ┌──────────────────────────────┐
│ 7                      │             │ 4 байти: n (int)             │
│ 4 8 -2 6 3 10 12       │             │ n × 4 байти: елементи (int)  │
└────────────────────────┘             └──────────────────────────────┘
```

**Завдання 1 — особливість:** у файлі лежать **обидва масиви одразу**: перше число `2N`, далі N елементів A, потім N елементів B. Так не треба двох файлів, а розмір A = розмір B гарантується самим форматом (якщо `2N` непарне — програма скаже, що розміри різні).

## 4. Розв'язок завдань

### 🔹 Завдання 1.8 — добуток двох масивів

`c[i] = a[i] · b[i]`

```
A = 1  2  3  4
B = 5 -6  7 -8
C = 5 -12 21 -32
```

Три вказівники `pa`, `pb`, `pc` йдуть паралельно: `*pc = *pa * *pb; pa++; pb++; pc++;`.

### 🔹 Завдання 2.8 — максимальний парний до першого непарного

Приклад: `4 8 -2 6 3 10 12` → до першого непарного (`3`) стоять `4 8 -2 6`, максимум = **8** (індекс 1). Елементи `10` і `12` після непарного — **не враховуються**.

```cpp
int* p = a;  int* best = NULL;
while (p < end && *p % 2 == 0) {      // зупиняємось на першому непарному
    if (best == NULL || *p > *best) best = p;
    p++;
}
```

**Граничні випадки:**
- перший елемент непарний (`3 4 6`) → «Парних елементів до першого непарного немає» (`best` лишився `NULL`);
- усі елементи парні → перевіряємо весь масив;
- парність від'ємних: `-2 % 2 == 0` ✔ (у C++ остача від'ємного ділимого має знак ділимого, але нуль є нуль), `-3 % 2 == -1` ≠ 0 → непарне.

### 🔹 Завдання 3.8 — корені рівняння

`x² + 3A·x + 5 = 0`

- Дискримінант: `D = (3A)² − 4·1·5 = 9A² − 20`.
- **Дійсні** корені: `D ≥ 0` → `9A² ≥ 20` → `|A| ≥ 2` (для цілих).
- **Додатні**: за теоремою Вієта `x₁ + x₂ = −3A`, `x₁·x₂ = 5`. Добуток додатний → корені **одного знака**; щоб обидва були додатні — сума додатна: `−3A > 0` → `A < 0`.
- Разом: **A ≤ −2**.

Приклад: `1 -1 -2 -3 5 -4 -10 2` → B = `-2 -3 -4 -10` (бо `-1`: D = 9−20 < 0, коренів немає; `1, 5, 2` — додатні A дають від'ємні корені).

Перевірка на `A = −2`: `x² − 6x + 5 = 0` → `x = 1` і `x = 5` ✔.

Друк по 5 у рядку: `if (i % 5 == 4) cout << endl;`.

## 5. Питання викладача та відповіді

### 📦 Масиви і пам'ять

**Чим динамічний масив відрізняється від статичного?**
Статичний: `int a[100]` — розмір відомий під час компіляції, лежить на стеку. Динамічний: `new int[n]` — розмір задається під час роботи, лежить у купі (heap), його треба звільнити `delete[]`.

**Чим `delete[]` відрізняється від `delete`?**
`delete[]` — для масивів, викликає деструктор кожного елемента й звільняє весь блок; `delete` — для одного об'єкта. Змішувати не можна.

**Що буде, якщо забути `delete[]`?**
Витік пам'яті: блок лишається зайнятим до завершення програми.

**Чому vector зручніший?**
Сам керує пам'яттю (RAII), має `size()`, `push_back()`, не потребує `delete`. Мінус — трохи більше накладних витрат.

**Що таке вказівник? Чим відрізняється `*p` від `p`?**
Вказівник — змінна, що зберігає адресу. `p` — адреса, `*p` — значення за цією адресою.

**Чому `a[i]` те саме, що `*(a + i)`?**
Додавання до вказівника зсуває його на `i` елементів (а не байтів). `a[i]` — запис цього ж через оператор індексування.

**Що дає `best - a`?**
Різниця двох вказівників на один масив = кількість елементів між ними, тобто індекс.

**Для чого `NULL`?**
Позначка «вказівник ні на що не вказує». У завданні 2 це означає «ще не знайшли жодного парного».

### 📁 Файли

**Як відкрити файл у бінарному режимі?**
`ofstream f("x.bin", ios::binary);` / `ifstream f("x.bin", ios::binary);`.

**Що робить `f.write((char*)a, n * sizeof(int))`?**
Записує блок пам'яті масиву як є, `n * 4` байтів. `(char*)` — бо `write` приймає `char*`.

**Чим текстовий файл відрізняється від бінарного?**
Текстовий — числа як рядки цифр (читабельний, довший). Бінарний — байти значень «як у пам'яті» (компактний, але потребує тієї ж архітектури).

**Навіщо в бінарному файлі першим пишемо `n`?**
Щоб при читанні знати, скільки елементів виділити й зчитати.

**Як перевірити, що файл відкрився?**
`if (!f)` після `open` / в конструкторі.

**Як працює `rand()`? Навіщо `srand(time(0))`?**
`rand()` дає псевдовипадкові числа; без `srand` послідовність щоразу однакова. `time(0)` — поточний час, тому «зерно» щоразу різне. `rand() % 41 - 20` дає числа від −20 до 20.

### 🧮 Завдання

**Чому в завданні 2 цикл зупиняється на першому непарному?**
Умова `*p % 2 == 0` у `while` стає хибною на непарному — цикл завершується; усе, що далі, не розглядається.

**А якщо перший елемент непарний?**
Цикл не виконається жодного разу, `best` лишиться `NULL` → повідомлення «немає».

**Чому в завданні 3 перевіряємо `a < 0`, а не лише дискримінант?**
Дискримінант ≥ 0 гарантує лише **дійсність**. Знак коренів дає теорема Вієта: сума `−3A`; для додатних коренів вона має бути > 0.

**Чому `9LL * a * a`?**
`LL` робить обчислення в `long long`, щоб `a*a` не переповнило `int` при великих `a`.

## 6. Правки «на льоту»

| Що попросять | Що змінити |
|---|---|
| Інша дія над масивами (`a[i] + b[i]`, `a[i] - b[i]`) | у `task1()`: рядок `*pc = *pa * *pb;` |
| До першого **від'ємного** замість непарного | умова `while`: `*p % 2 == 0` → `*p >= 0` (і враховувати парність у тілі) |
| Мінімум замість максимуму | `*p > *best` → `*p < *best` |
| Після першого непарного | спочатку пропустити парні (`while (p<end && *p%2==0) p++;`), далі шукати від `p` |
| Інше рівняння `x² + 3Ax + 5` | змінити дискримінант `9*a*a - 20` і умову знака в `rootsPositive` |
| Друк по 4 у рядку | `i % 5 == 4` → `i % 4 == 3`, `m % 5` → `m % 4` |
| Інший діапазон випадкових | `rand() % 41 - 20` → `rand() % (max - min + 1) + min` |
| Масив типу double | замінити `int` на `double` у `writeI/readI/showI` і в завданні |

## 7. Код з коментарями

```cpp
#include <iostream>
#include <fstream>
#include <vector>
#include <cstdlib>
#include <ctime>

using namespace std;

void writeI(const char* name, int* a, int n, bool binary) {  // запис масиву у файл: binary=true → бінарний, false → текстовий
    if (binary) {
        ofstream f(name, ios::binary);
        f.write((char*)&n, sizeof(n));  // бінарний файл: спочатку кількість елементів (4 байти)...
        f.write((char*)a, n * sizeof(int));  // ...потім самі елементи одним блоком
        f.close();
    } else {
        ofstream f(name);
        f << n << endl;  // текстовий файл: у першому рядку кількість
        for (int i = 0; i < n; i++) {
            f << a[i] << " ";  // ...у другому — елементи через пробіл
        }
        f << endl;
        f.close();
    }
}

int* readI(const char* name, int& n, bool binary) {  // читання: повертає НОВИЙ динамічний масив (потім треба delete[])
    ifstream f;
    if (binary) {
        f.open(name, ios::binary);
    } else {
        f.open(name);
    }
    if (!f) {
        cout << "Файл " << name << " не знайдено!" << endl;  // перевірка, що файл існує
        n = 0;
        return NULL;
    }
    if (binary) {
        f.read((char*)&n, sizeof(n));
    } else {
        f >> n;
    }
    if (!f || n < 0) {  // захист від порожнього/пошкодженого файлу
        cout << "Файл " << name << " пошкоджений!" << endl;
        n = 0;
        return NULL;
    }
    int* a = new int[n];  // динамічний масив потрібного розміру
    if (binary) {
        f.read((char*)a, n * sizeof(int));
    } else {
        for (int i = 0; i < n; i++) {
            f >> a[i];
        }
    }
    f.close();
    return a;
}

void showI(const char* name, bool binary) {  // читає файл у vector і друкує його
    int n;
    int* a = readI(name, n, binary);
    if (a == NULL) {
        return;
    }
    vector<int> v;  // контейнер vector — розмір росте сам
    for (int i = 0; i < n; i++) {
        v.push_back(a[i]);  // додаємо елемент у кінець вектора
    }
    delete[] a;  // масив уже скопійовано у vector — звільняємо пам'ять
    cout << "Вектор з файлу " << name << ":" << endl;
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }
    cout << endl;
}

void printMenu(int task) {  // одна функція меню на всі три завдання
    cout << endl << "--- Завдання " << task << ".8 ---" << endl;
    cout << "1 - ввести дані з клавіатури (текстовий файл)" << endl;
    cout << "2 - згенерувати дані (бінарний файл)" << endl;
    cout << "3 - розв'язати (з текстового файлу)" << endl;
    cout << "4 - розв'язати (з бінарного файлу)" << endl;
    cout << "5 - показати текстовий файл через vector" << endl;
    cout << "6 - показати бінарний файл через vector" << endl;
    cout << "0 - назад" << endl;
    cout << "Ваш вибір: ";
}

void task1() {
    int choice;
    do {
        printMenu(1);
        cin >> choice;

        if (choice == 1) {
            int n;
            cout << "Введіть n: ";
            cin >> n;
            int* a = new int[2 * n];  // завдання 1: в одному масиві 2n елементів — спочатку A, потім B
            for (int i = 0; i < n; i++) {
                cout << "A[" << i << "] = ";
                cin >> a[i];
            }
            for (int i = 0; i < n; i++) {
                cout << "B[" << i << "] = ";
                cin >> a[n + i];  // елементи B лежать починаючи з індексу n
            }
            writeI("task1_input.txt", a, 2 * n, false);
            delete[] a;
            cout << "Записано в task1_input.txt" << endl;
        }
        else if (choice == 2) {
            int n;
            cout << "Введіть n: ";
            cin >> n;
            int* a = new int[2 * n];
            for (int i = 0; i < 2 * n; i++) {
                a[i] = rand() % 41 - 20;  // випадкове число від −20 до 20
            }
            writeI("task1_input.bin", a, 2 * n, true);
            cout << "Згенерований масив A:" << endl;
            for (int i = 0; i < n; i++) {
                cout << a[i] << " ";
            }
            cout << endl << "Згенерований масив B:" << endl;
            for (int i = n; i < 2 * n; i++) {
                cout << a[i] << " ";
            }
            cout << endl;
            delete[] a;
            cout << "Записано в task1_input.bin" << endl;
        }
        else if (choice == 3 || choice == 4) {
            int total;
            int* a;
            if (choice == 3) {
                a = readI("task1_input.txt", total, false);
            } else {
                a = readI("task1_input.bin", total, true);
            }
            if (a != NULL) {
                if (total % 2 != 0) {  // якщо елементів непарна кількість — A і B різного розміру
                    cout << "Масиви A і B мають різний розмір!" << endl;
                } else {
                    int n = total / 2;
                    int* pa = a;  // вказівник на поточний елемент A
                    int* pb = a + n;  // вказівник на початок B (за n елементів від початку)
                    int* c = new int[n];  // результуючий масив C
                    int* pc = c;

                    cout << "Масив A:" << endl;
                    for (int i = 0; i < n; i++) {
                        cout << pa[i] << " ";
                    }
                    cout << endl << "Масив B:" << endl;
                    for (int i = 0; i < n; i++) {
                        cout << pb[i] << " ";
                    }
                    cout << endl;

                    while (pa < a + n) {  // йдемо, поки pa не дійшов до кінця A
                        *pc = *pa * *pb;  // c[i] = a[i] · b[i] через вказівники
                        pa++;  // усі три вказівники переходять на наступний елемент
                        pb++;
                        pc++;
                    }

                    cout << "Масив C = A * B:" << endl;
                    for (int i = 0; i < n; i++) {
                        cout << c[i] << " ";
                    }
                    cout << endl;
                    writeI("task1_result.txt", c, n, false);
                    cout << "Результат записано в task1_result.txt" << endl;
                    delete[] c;
                }
                delete[] a;
            }
        }
        else if (choice == 5) {
            showI("task1_input.txt", false);
        }
        else if (choice == 6) {
            showI("task1_input.bin", true);
        }
    } while (choice != 0);
}

                    cout << "Номер елемента (з нуля): " << index << endl;
                    f << "Значення: " << *best << ", номер (з нуля): " << index << endl;
                }

            }

bool rootsPositive(int a) {  // завдання 3: чи мають x² + 3Ax + 5 = 0 дійсні й додатні корені
    long long d = 9LL * a * a - 20;  // дискримінант D = (3A)² − 4·5 = 9A² − 20
    if (d < 0) {  // D < 0 → коренів немає
        return false;
    }
    return a < 0;  // сума коренів = −3A > 0 ⇒ A < 0 (добуток 5 > 0 — корені одного знака)
}
```
