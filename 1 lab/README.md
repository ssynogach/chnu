# Лабораторна робота №1 — ООП мовою C++, варіант 11

## Що реалізовано

| Пункт методички | Де в коді |
|---|---|
| a) введення масиву з консолі + запис у текстовий файл | пункт **1** у меню кожного завдання |
| b) розмір з консолі, датчик випадкових чисел, запис у бінарний файл | пункт **2** |
| c) розв'язання задачі на **динамічних масивах**, дані з файлу → результат у новий файл + консоль | пункти **3** (текстовий) і **4** (бінарний) |
| d) читання з файлу в контейнер `std::vector` і вивід у консоль | пункт **5** |
| меню у `main()` | `main.cpp` |

Задачі варіанту 11:

1. **Завдання 1.** Першу половину елементів масиву помножити на 2, другу — на 3.
   *(при непарному N перша половина — це N/2 елементів, середній потрапляє у другу)*
2. **Завдання 2.** Номер останнього мінімального елемента серед парних додатних елементів, що лежать правіше першого від'ємного. Обробка виконана через змінну-вказівник `pCur` на поточний елемент, індекс отримано адресною арифметикою `pMin - a`.
3. **Завдання 3 (додаткове).** Кількість точок множини, що належать трикутнику ABC. Використано знак векторного добутку; точки на межі вважаються такими, що належать трикутнику.

## Структура проєкту

```
main.cpp        головне меню
utils.h/.cpp    безпечне введення з консолі, створення каталогу data/
arrays_io.h/.cpp  шаблонні функції запису/читання масивів (текст і бінар), вивід, генератор випадкових чисел
task1.h/.cpp    Завдання 1
task2.h/.cpp    Завдання 2
task3.h/.cpp    Завдання 3
.vscode/        конфігурація збірки та відладки
data/           створюється автоматично, тут усі вхідні та вихідні файли
```

Формати файлів:

* **текстовий**: перший рядок — `n`, далі значення;
* **бінарний**: `int n`, далі `n` значень підряд (`write`/`read` блоками).

## Налаштування VS Code (Windows)

1. Встанови розширення **C/C++** від Microsoft.
2. Встанови компілятор — найпростіше **MSYS2**: https://www.msys2.org
   Після встановлення у вікні MSYS2 виконай:
   ```
   pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
   ```
   Потім додай `C:\msys64\ucrt64\bin` у змінну середовища **Path** (Пуск → «Змінні середовища»).
3. Перезапусти VS Code і перевір у терміналі:
   ```
   g++ --version
   gdb --version
   ```
   Якщо версії виводяться — усе готово.
4. Відкрий папку проєкту (**File → Open Folder**, саме папку, не окремий файл).
5. **Ctrl+Shift+B** — збірка. **F5** — запуск під відладчиком.

У `launch.json` для Windows може знадобитися замінити:
```
"program": "${workspaceFolder}/lab1"      →  "${workspaceFolder}/lab1.exe"
"miDebuggerPath": "gdb"                   →  "C:/msys64/ucrt64/bin/gdb.exe"
```
і в `tasks.json` відповідно `"-o", "${workspaceFolder}/lab1.exe"`.

Якщо замість українського тексту в консолі видно кракозябри — виконай у терміналі `chcp 65001` (у коді вже стоїть `SetConsoleOutputCP(CP_UTF8)`, зазвичай цього достатньо).


## Засоби налагодження (пункт методички про debug)

Для звіту/захисту достатньо показати:
* точку зупинки на рядку `multiplyHalves(a, n);` у `task1.cpp` — далі **Step Into (F11)** заходить у функцію;
* у вікні **Variables** видно `a`, `n`, `pCur`;
* у **Watch** додай вираз `a[0]`, `*pCur`, `pMin - a` — покроково видно, як рухається вказівник у `solveTask2`.
